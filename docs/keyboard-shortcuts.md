# Keyboard Shortcuts

Shortcuts apply to the file list unless the focus is in a text field. The same
list is available in the app from the command palette or the keyboard help
dialog.

In dual pane, navigation shortcuts, tabs, search, sort, view, hidden files, and
quick filter apply to the **active** pane. `Tab` switches which pane is active.
The toolbar path bar (`Ctrl+L`) shows and edits that pane's location.

## Navigation

| Shortcut | Action |
|---|---|
| `Enter` | Open the selected item |
| `Backspace` | Go up one folder |
| `Arrow keys` | Move the highlight |
| `Home` | First item |
| `End` | Last item |
| `Ctrl+L` | Focus the path bar |
| `Tab` | Switch panes when dual pane is on |

## Selection

| Shortcut | Action |
|---|---|
| `Ctrl+A` | Select all |
| `Shift+Arrow` | Extend the selection |
| `Ctrl+Click` | Toggle one item |
| `Shift+Click` | Select a range |
| `Escape` | Clear selection, close menus, or close the top overlay |

## File operations

| Shortcut | Action |
|---|---|
| `Ctrl+C` | Copy |
| `Ctrl+X` | Cut |
| `Ctrl+V` | Paste |
| `Ctrl+Shift+V` | Clipboard history |
| `Ctrl+Z` | Undo |
| `Ctrl+Y` or `Ctrl+Shift+Z` | Redo |
| `Delete` | Move to trash, or delete if trash is unavailable |
| `F2` | Rename the selected item |
| `Ctrl+N` | New folder |
| `Ctrl+Shift+N` | New file |

Advanced Rename has no default shortcut. Open it from the context menu or the
command palette.

## View and tools

| Shortcut | Action |
|---|---|
| `Space` | Quick Look |
| `Ctrl+F` | Focus search |
| `/` or `Ctrl+Shift+F` | Quick filter in the current folder |
| `Ctrl+Shift+D` | Find duplicate files |
| `Ctrl+Shift+P` | Command palette |
| `Ctrl+H` | Toggle hidden files |
| `F4` | Open a terminal in the current folder |
| `F5` | Refresh the active pane |
| `F6` | Toggle dual pane |

## Tabs and bookmarks

| Shortcut | Action |
|---|---|
| `Ctrl+T` | New tab |
| `Ctrl+W` | Close the current tab |
| `Ctrl+D` | Bookmark the current folder |
