# Support

## Before you ask

1. Read the [README](../README.md) and the [user guide](user-guide.md).
2. Search [existing issues](https://github.com/conniecombs/SimpleFile-Linux/issues).
3. Check [Discussions](https://github.com/conniecombs/SimpleFile-Linux/discussions)
   if that board is enabled on the repository.

## Where to go

| Need | Place |
|---|---|
| How do I use SimpleFile? | [User guide](user-guide.md) or GitHub Discussions |
| Something is broken | [Bug report](https://github.com/conniecombs/SimpleFile-Linux/issues/new?template=bug_report.md) |
| I want a feature | [Feature request](https://github.com/conniecombs/SimpleFile-Linux/issues/new?template=feature_request.md) |
| Security issue | [Security advisories](https://github.com/conniecombs/SimpleFile-Linux/security/advisories/new) — never a public issue |
| I want to contribute | [CONTRIBUTING.md](CONTRIBUTING.md) |

## A useful bug report

Include:

- Linux distribution and version (for example Ubuntu 24.04, Fedora 42)
- Desktop session (GNOME, KDE, Sway, and whether it is Wayland or X11)
- SimpleFile version from **Settings → About**
- Exact steps to reproduce
- What you expected
- What happened, including error text or a screenshot

Reports without this information will be asked for it before anyone can
investigate.

## Response time

This is a community-maintained project. Replies are best-effort. Data-loss
bugs and startup crashes are handled first.
